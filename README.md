# Esgrima 2 Beta

[Download the Windows installer](https://github.com/Veaxxon/esgrima2-downloads/releases/latest/download/Esgrima2Setup.exe)

Run **Esgrima2Setup.exe** and choose an installation folder. Setup downloads and verifies the game automatically. Open the **Esgrima 2** desktop shortcut to play. No Godot editor or Python installation is needed.

Use **Check for updates** in the launcher for new versions. The launcher preserves the installed version if an update fails.

For launch problems, click **Open logs** and send the launcher log and latest game log with your bug report.

Online play requires the game server to be running.
